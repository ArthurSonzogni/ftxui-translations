## Paquet openSUSE (Non officiel)

FTXUI semble être disponible depuis le dépôt `devel:libraries:c_c++`.

```bash
sudo zypper addrepo https://download.opensuse.org/repositories/devel:libraries:c_c++/openSUSE_Leap_$releasever/devel:libraries:c_c++.repo
sudo zypper install ftxui
```

Voir <https://build.opensuse.org/package/show/devel:libraries:c_c++/ftxui> pour plus de détails.

> [!note]
> Ceci est un paquet **non officiel**. Cela signifie qu'il n'est pas maintenu par l'équipe FTXUI, mais par la communauté.
