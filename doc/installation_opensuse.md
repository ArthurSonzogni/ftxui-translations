## openSUSE パッケージ (非公式)

FTXUI は `devel:libraries:c_c++` リポジトリから入手できるようです。

```bash
sudo zypper addrepo https://download.opensuse.org/repositories/devel:libraries:c_c++/openSUSE_Leap_$releasever/devel:libraries:c_c++.repo
sudo zypper install ftxui
```

詳細については <https://build.opensuse.org/package/show/devel:libraries:c_c++/ftxui> を参照してください。

> [!note]
> これは**非公式**パッケージです。つまり、FTXUI チームではなく、コミュニティによってメンテナンスされています。
