## Paquete openSUSE (No oficial)

FTXUI parece estar disponible en el repositorio `devel:libraries:c_c++`.

```bash
sudo zypper addrepo https://download.opensuse.org/repositories/devel:libraries:c_c++/openSUSE_Leap_$releasever/devel:libraries:c_c++.repo
sudo zypper install ftxui
```

Consulta <https://build.opensuse.org/package/show/devel:libraries:c_c++/ftxui> para más detalles.

> [!note]
> Este es un paquete **no oficial**. Esto significa que no es mantenido por el equipo de FTXUI, sino por la comunidad.
